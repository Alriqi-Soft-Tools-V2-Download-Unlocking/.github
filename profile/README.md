## 💡 What Is FRP?

FRP stands for **Factory Reset Protection**. It is a security mechanism used on supported Android devices to help prevent unauthorized use after a factory reset.

When protection is active, the device may request verification using an account previously associated with it. This helps protect the owner's information if a phone is lost or reset without permission.

If you own the device but cannot complete verification, consider these legitimate options:

- Recover access to the Google account associated with the phone.
- Follow the on-screen account verification instructions.
- Contact the seller if the phone was purchased second-hand.
- Seek assistance from an authorized service center with proof of ownership.
